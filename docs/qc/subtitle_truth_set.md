# 字幕真值集验收规范（S2.3）

- 状态：**真值集尚未标注（需人工，约 0.5 天）**。在真值入库之前，本项目**不承诺 `<300ms` 字幕对齐指标**，
  对外口径一律为「预览级对齐」（对应综合方案 R4：有真值才承诺，不造假指标）。

## 1. 真值集要求

- 规模：20~30 句，覆盖至少 2 个音色无关的示例文档（短文 + 含数字/表格文档各一）。
- 来源：用真实 edge-tts 音频 + 人耳/波形工具标注，禁止用管线自身输出当真值（避免自证）。
- 格式：`docs/qc/truth/<样例名>.truth.json`（全片时间轴，单位秒）：

```json
{
  "target_ms": 300,
  "segments": [
    {"text": "咖啡因通过阻断腺苷受体起作用。", "start_s": 1.24, "end_s": 3.58, "scene_id": "sc01"}
  ]
}
```

## 2. 标注规范

1. 起止点以音频波形中人声首个可辨音节/末个音节收尾为准，精度 20ms。
2. 一句对应一条 segment；语气词并入相邻句。
3. 标点不计时；背景音（BGM）不影响边界判定。

## 3. 复核机制

- 标注完成后**隔日自检复核一遍**（同一标注人换时段重标 20% 抽样，起止偏差需 <50ms，否则全部返工）。
- 真值文件与验收报告一起版本化入库，修改真值必须提交变更说明。

## 4. 评测与判定

- 命令：`uv run python -m scripts.subtitle_eval --job <job_dir> --truth <truth.json>`
- 指标：句起止误差 P50/P95/max、覆盖率（IoU≥0.3 视为匹配）。
- 判定：覆盖率 ≥90% 且起止误差 P95 ≤ target_ms → 保留 `<300ms` 承诺；
  否则**删除硬承诺、降级为预览级口径**（修改口径而非放宽阈值）。
- 报告落盘：`<job>/qc/subtitle_eval.json`；发布候选的评测结果随验收报告入库 `docs/release/`。

## 5. 当前结论

| 项 | 结论 |
|---|---|
| `<300ms` 承诺 | **暂不生效**（无真值支撑，2026-08-28） |
| 主路径 | edge-tts native marks（S1.1 已闭环）；whisper 兜底有置信度记录 |
| forced aligner | 显式延期至二期（综合方案 S4） |
