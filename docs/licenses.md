# 许可证结论（S3.5）

本文档按分发模式给出许可证结论，是**发布阻断条件**之一：分发形态未决策前，
任何对外交付默认按最严格路径（内部使用）执行。法律解释以法务意见为准，
本文档只做工程侧的事实梳理与决策矩阵；**标注「人工确认」的条目代码不代办**。

## 1. 依赖许可证事实（2026-08-28 核对 `pyproject.toml`）

| 依赖 | 许可证 | 风险点 |
|---|---|---|
| `pymupdf` | **AGPL-3.0 / 商业双许可** | 网络传播即触发 AGPL 开源义务；闭源分发必须购买商业许可或替换 |
| `edge-tts`（库） | MIT | 库本身宽松；但调用的是微软 Edge TTS 服务，受微软服务条款约束（见第 3 节） |
| `faster-whisper` | MIT | 模型权重（Systran/faster-whisper-*）随 CTranslate2 转换，上游 OpenAI Whisper 为 MIT |
| `rapidocr-onnxruntime` | Apache-2.0 | 检测/识别模型权重另需确认其上游许可（人工确认） |
| `python-docx` / `markdown-it-py` / `httpx` / `pydantic` / `jsonschema` | MIT / BSD 系 | 保留版权声明即可 |
| `python-dotenv` / `pyyaml` | BSD / MIT | 无阻断 |
| `pillow` | HPND（MIT 风格） | 无阻断 |
| `pyjianyingdraft` | 宽松开源（人工确认具体条款） | 仅本地生成草稿文件，无网络调用 |
| `ffmpeg`（外部二进制） | **取决于构建**：官方/常见 Windows 发行版为 GPL | GPL 构建与闭源产物捆绑分发会传染；LGPL 构建 + 动态链接可缓解 |
| 字体 `Microsoft YaHei`（`config.subtitle.font`） | 随 Windows 授权，**禁止脱离系统再分发** | 不得把字体文件打进产物包；渲染只在本机调用系统字体 |

## 2. 分发形态决策矩阵

| 分发形态 | PyMuPDF | ffmpeg | 字体 | 结论 |
|---|---|---|---|---|
| **A. 内部工具**（仅本组织内使用，不分发二进制） | 无需商业许可（AGPL 的开源义务由"分发/网络传播"触发；纯内部 + 不对外提供服务即可） | 任意构建 | 使用系统字体即可 | **当前默认形态，无阻断** |
| **B. 闭源对外分发**（交付可执行包/安装包给外部） | 阻断：必须购买 Artifex 商业许可，或将 PDF 解析替换为宽松许可实现（如 `pypdf`，功能降级需评估） | 阻断：须改用 LGPL 构建且满足动态链接条件，或要求用户自备 ffmpeg | 阻断：不得捆绑字体；文档注明目标机器需具备 CJK 字体 | 未完成上述任一项前禁止该形态 |
| **C. 开源发布**（AGPL 或更宽松整体开源） | 兼容（AGPL 对 AGPL） | GPL 构建可捆绑（整体 GPL 兼容） | 仍不得捆绑雅黑；改用 OFL 字体（如思源黑体）作为默认 | 可行，但项目整体许可须 ≥ AGPL |

## 3. 运行时服务的权利（非代码许可，人工确认）

| 服务 | 事实 | 待人工确认 |
|---|---|---|
| Microsoft Edge TTS | 库通过公开接口调用微软服务；音色 `zh-CN-XiaoxiaoNeural` 等 | 商用产出物的权利以微软服务条款为准；敏感/商用发布前确认条款允许用途 |
| FAL 图像生成 | 按账户计费，生成图像权利以 FAL 条款与所用模型许可为准 | 商用分发成片前确认模型输出可商用（人工确认） |
| Ollama + qwen3 | 本地推理，无外发 | 模型权重许可（Qwen 系列条款）在对外分发衍生内容时人工确认 |

## 4. 发布阻断与放行规则（工程口径）

1. **未决策分发形态前，`release_gate` 通过的产物仅限内部使用**（形态 A）。
2. 形态 B 的第一次对外交付前必须：完成 PyMuPDF 商业许可采购或依赖替换 +
   ffmpeg LGPL 构建核实 + 字体策略书面确认（三项均为人工环节，记录归档）。
3. 字体与音色**永不进入产物包**：成片只含渲染结果；`doctor` 检查系统字体存在性而非捆绑。
4. 本文档任何结论变更（换依赖、换构建、签新条款）必须同步更新本文件并在
   `release_gate` 报告旁留痕（人工确认记录随 `docs/release/` 归档）。
